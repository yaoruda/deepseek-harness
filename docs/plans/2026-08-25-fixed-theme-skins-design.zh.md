# 固定主题皮肤设计

[English](2026-08-25-fixed-theme-skins-design.md) | 中文

## 目标

为 Web 应用增加三种整页皮肤选择：Harness 默认、赛博朋克和莫兰迪。`assistant.ruda.work` 与回环地址首次使用赛博朋克，`ailin.ruda.work` 首次使用莫兰迪，其他主机保留 Harness 默认外观。手机、已安装 PWA 和电脑宽度使用相同行为。

## 包归属

一个新的客户端插件拥有固定定义、浏览器本地偏好、可配置的主机名默认值解析器和通用设置行，由 Web bundle 提供本部署的域名映射。它通过 `ThemeRuntime.register()` 注册赛博朋克与莫兰迪，通过 `ThemeRuntime.setTheme()` 完成切换。现有 ui-theme 包继续拥有主题状态、DOM 展示、语义颜色 token，以及内置的亮色、深色和跟随系统偏好。

皮肤插件不导入会话、地图、设置或布局组件。这些包继续消费语义 `--dsw-*` 变量。插件可以持有一张小型样式表，通过 `body[data-dsh-skin]` 添加皮肤专用背景处理，但不得替换组件布局或排版规则。

## 偏好语义

版本化浏览器键 `dsh.skin-preset.v1` 只接受 `default`、`cyberpunk` 或 `morandi`。缺少保存值时根据当前主机名解析。保存的 `default` 表示明确退出主机名默认皮肤，并选择内置的 `system` 偏好。无效值、存储被拒绝和未知主机均安全回退，不会阻止客户端插件树加载。

选择仅属于一个浏览器源。两个公开域名因此自然独立，无需削弱仅限回环地址访问的 Host 设置 API。本地与公开部署使用同一插件和构建产物，只有首次使用的主机名解析结果不同。

## 视觉定义

赛博朋克使用深石墨与蓝黑基础色、机械分层表面、青色和电蓝交互强调、克制的洋红状态点缀、冷色边框，以及静态低对比度网格或径向冷光。它不使用持续动画。莫兰迪使用暖米白、鼠尾草灰绿、雾蓝、沙色和低饱和陶土色，通过低对比度层级保持柔和，并确保文字清晰。

两套定义覆盖应用基础、侧栏、抬升表面、浮层、边框、主要与次要文字、品牌操作、状态、气泡、代码、表格和滚动条使用的语义变量。地图瓦片保留来源颜色，周围控件和面板跟随所选皮肤。显示密度变量和移动端 16 px 输入框规则保持独立。

## 生命周期与失败处理

插件在使用前校验存储，先注册两套主题再选择当前皮肤，并从一次用户操作同时更新自己的存储、主题运行时、本地存储和 `data-dsh-skin`。资源释放时只移除仍由插件持有的注册和文档属性。活动的注册主题消失时，ThemeRuntime 恢复内置默认值。

通用设置行展示三个固定选择和简短的当前设备说明。切换立即生效，不会开始 Session 轮次或模型请求。

## 验证

单元测试覆盖主机名解析、明确恢复默认、存储失败、注册顺序、选择、持久化和资源释放。无密钥组装浏览器测试覆盖三个设置选项、电脑与 390 px 宽度下的实际语义颜色、重新加载保持、明确恢复 Harness 默认、显示密度兼容和无控制台错误。生产构建、类型检查、文档门禁、定向 UI 测试与真实本地 HTTP 响应构成本地发布证据。

服务器部署复用本地构建产物，并为两套 Harness 服务激活同一个提交。验收要求两个回环服务和新客户端插件均返回 HTTP 200，两个公开域名的未认证请求均跳转到 Authelia，并且 3080 与 3081 端口继续无法从公网访问。
