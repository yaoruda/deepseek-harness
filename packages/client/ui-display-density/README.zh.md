# @deepseek-ai/dsh-client-ui-display-density

[English](README.md) | 中文

浏览器本地会话密度插件。首次使用时，它把不超过 720 CSS 像素的手机宽度视口解析为紧凑，更宽的视口解析为标准，通过 `body[data-dsh-display-density]` 投影当前预设，并在通用设置中注册标准、紧凑和超紧凑选择器。

经过校验的偏好存储在当前浏览器配置的 `dsh.display-density.v1` 下。它不会写入 Host 设置，因此不会在设备或用户之间同步。存储被拒绝或数据格式错误时会回退到基于宽度的默认值，不会阻止当前文档工作。

该插件选择由 [ui-theme](../ui-theme/README.zh.md) 持有并全局装载的共享显示密度变量；会话和 Markdown 组件把适用的变量映射到自己的排版和表格样式。标准模式保留现有电脑端尺寸。紧凑模式缩小会话文字、表格文字、表格单元格、用户气泡和 transcript（文本记录）间距。超紧凑模式把这些值再缩小一级。所有模式下的输入框文字都保持 16 px，以避免 iOS 聚焦放大；文档 viewport 仍允许手动缩放。

## 模型体验

无，因为显示密度只改变浏览器展示，不会增加模型输入、工具 schema、提示词或 Session 事件。

#### KV Cache 影响

无。切换显示密度既不会开始轮次，也不会重新构建模型请求。

## 已知限制与暂缓事项

- 偏好设置属于浏览器配置，不会跨设备同步。
- 工具专用卡片、地图、代码块和应用外壳保留各功能自己的尺寸。
- 首次默认值在插件激活时解析；跨越手机宽度断点调整窗口大小时，重新加载前不会替换当前选择。
